# Contributing to academy-templates

Thanks for your interest in contributing templates!

Guidelines:
1. Fork the repository and create a branch for your contribution.
2. Add your YAML template under an appropriate category inside `templates/` (web, cloud, ai).
3. Each template must include an `id`, `info`, `environment`, `scenario`, and `validation` section.
4. Open a pull request describing your lab and include any required assets.

We review contributions and merge them when they meet quality and safety guidelines.
