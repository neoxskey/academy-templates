# Academy Templates

## Introduction

This repository contains community-driven templates designed for various hacking scenarios. Each template is designed to be a resource for hacktivists, educators, and learners.

## Features

- **Community-Driven**: Contributions from various users enhance the quality and breadth of available templates.
- **XP System**: Users can earn experience points (XP) for their contributions, which can be used to showcase expertise.

## How to Submit .study Templates

1. **Fork the Repository**: Start by forking this repository to your account.
2. **Create a New Branch**: Create a branch from the main branch for your template.
3. **Add Your Template**: Place your .study file in the designated folder according to its category.
4. **Document Your Work**: Provide a clear description of the template’s purpose and usage within the README.
5. **Submit a Pull Request**: Once your changes are ready, submit a pull request for review.
   
## Conclusion

Your contributions help build a better learning environment and resources for everyone involved in hacking education. Thank you for being part of our community!
